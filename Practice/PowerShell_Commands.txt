PowerShell commands 

Run these commands from the project folder:

cd "H:\study\Study 1.0\Study"

Activate the Python 3.15 virtual environment:
.\.venv315\Scripts\Activate.ps1

Check which Python version is active:
python --version

Run the Morse code translator:
python ".\Practice\Morse_Code_Translator.py"

You can also run it with the full Python path:
& "C:\Users\Resfort\AppData\Local\Python\pythoncore-3.15-64\python.exe" "H:\study\Study 1.0\Study\Practice\Morse_Code_Translator.py"

Put quotes around the whole file path only. Do not put quote characters inside the path,
for example, do not pass '"H:\study\Study 1.0\Study\Practice\Morse_Code_Translator.py"'
as one argument.

When finished, deactivate the virtual environment:
deactivate

To use the older .venv environment instead, activate it with:
.\.venv\Scripts\Activate.ps1
